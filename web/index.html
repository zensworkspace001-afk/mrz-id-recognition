匯出

SQL 檔怎麼匯入？

SQL 檔要用查詢工具執行：pgAdmin 請用 Query Tool 開啟檔案後按執行（F5），不要用 Restore（Restore 只接受 pg_dump 備份檔）；MySQL 用 Workbench 或 mysql < 檔案；SQL Server 用 SSMS。資料表不存在會自動建立，已存在就直接寫入；同一張照片重複匯入會更新，不會重複新增。

結果只保留在這個瀏覽器分頁，重新整理就會清除；匯出的檔案含個人資料，請妥善保管。

護照 2 行 × 44 字元，或卡片 3 行 × 30 字元；會顯示每個檢查碼「印的」和「依資料算出應為」的值。

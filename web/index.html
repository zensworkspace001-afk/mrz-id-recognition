證件辨識驗證

上傳護照或居留證照片，檢查這套流程能不能讀對。只在這台電腦上處理，照片不會存檔。

展示用網站，請勿上傳真實證件。照片會傳到雲端伺服器處理（只在記憶體中、不儲存），但仍屬於把個資交給第三方。 請用下方的合成範例圖試用；真實證件請在本機或公司內部部署的版本處理。
試用合成範例：

每張照片會先檢查能不能用（約 1 秒），再辨識（約 3～15 秒）。拍攝建議：MRZ（底部兩三行英數字）清楚、不反光；證件可以歪斜或旋轉，護照可以整本打開拍。

暫存區

匯出檔名照片檢查辨識結果姓名證件號碼

免複核的預設勾選；需複核的請看過詳細結果、確認無誤後再勾選（會記為已人工確認）。建議重拍與失敗的不能匯出。

SQL 檔要用查詢工具執行：pgAdmin 請用 Query Tool 開啟檔案後按執行（F5），不要用 Restore（Restore 只接受 pg_dump 備份檔）；MySQL 用 Workbench 或 mysql < 檔案；SQL Server 用 SSMS。資料表不存在會自動建立，已存在就直接寫入；同一張照片重複匯入會更新，不會重複新增。結果只保留在這個瀏覽器分頁，重新整理就會清除；匯出的檔案含個人資料，請妥善保管。

範例：

會顯示每個檢查碼「印的」和「依資料算出應為」的值。兩張移民署樣張的總檢查碼都與 ICAO 公式不符（居留證樣張印 8、算得 3），請用真實卡片確認。
